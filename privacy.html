Privacy Policy

GTNH Backups is a personal utility operated by BeeTwin.

The utility uploads existing Minecraft world backup archives to the owner's Google Drive. Archives may contain player identifiers and game progress. It accesses backup file names, sizes and checksums to verify uploads and manage retention.

Google Drive access uses the drive.file permission, limited to files created by this application. OAuth credentials are stored on the owner's server and used only to authorize backup operations.

Backup data is processed on the owner's server and stored by Google Drive. The operator does not sell this data or share it with advertisers. No advertising or analytics are added by this utility.

The retention target is the seven most recent successfully uploaded backups. Older copies are deleted after successful upload verification. The owner may manually delete backups and revoke access through Google Account settings. Revoking access does not delete existing files.

This documentation site is hosted by GitHub Pages. GitHub and Google process service-related information under their own privacy policies.

Contact: GitHub Issues. Do not post credentials or private backup contents.
